# AI Sentiment Analysis

A machine learning model capable of detecting the sentiment of a text (classifying them into 6 distinct feelings). The dataset used for training consists of over 16,000 labeled tweets. This project was created as an exercise to learn the basics of data preprocessing and
 the implementation of machine learning models using Python.

## Features

- **Data cleaning**: Removing stopwords, punctuation, special characters, and more.
- **Data visualization**: Word frequency analysis and word clouds.
- **Training of multiple classifiers**:
  - Logistic Regression
  - Naive Bayes
  - K-Nearest Neighbors
  - Decision Trees
  - Random Forest
  - Linear SVM
  - Multilayer Perceptron (MLP)
  - Perceptron
  - Bagging
  - Gradient Boosting
  - Extra Trees
  - Ridge Classifier
  - Passive Aggressive
  - Stochastic Gradient Descent (SGD)
- **Performance evaluation**: Accuracy, precision, recall, and F1-score.
- **Evaluation of results** with confusion matrices and the previous performance metrics.
- **Text classification**: Input a custom sentence to obtain its sentiment.
